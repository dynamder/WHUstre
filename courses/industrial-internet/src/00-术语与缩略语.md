# 缩略语与术语总表

课件大量直接使用缩写与专有名词而不作解释：一句话里出现 OPC UA、MTCconnect、YANG 三个协议名，或直接说“OT 层不再可信”，却不说明 OT 是什么。这份表把它们统一解释一次，按用途分组。章内首次出现时也只作简短展开，完整说明看这里。工厂现场类名词（现场、车间、产线、工位、节拍、工单、换型、在制品、稼动率）见第零章。

## 2 网络与通信协议

| 缩写 | 全称 | 说明 |
| --- | --- | --- |
| IT | Information Technology | 信息技术，对应办公、管理类系统，追求吞吐与通用性 |
| OT | Operational Technology | 运营技术，对应生产控制类系统，追求周期确定与不停机 |
| IP | Internet Protocol | 互联网协议；IPv4／IPv6 是它的两个版本，差别主要在地址空间 |
| TCP | Transmission Control Protocol | 传输控制协议，提供可靠、有序的字节流 |
| UDP | User Datagram Protocol | 用户数据报协议，不保证送达，换来低开销 |
| HTTP | Hypertext Transfer Protocol | 超文本传输协议，Web 的数据传输协议 |
| QoS | Quality of Service | 服务质量，按业务给不同流量分配带宽与优先级 |
| CSMA/CD | Carrier Sense Multiple Access with Collision Detection | 载波监听多路访问／冲突检测，标准以太网的介质访问方式；冲突后随机退避重传，所以时延不可界 |
| WSN | Wireless Sensor Network | 无线传感器网络，节点自组织、协同感知，经网关接入公用网络 |

| LoRa | Long Range | 远距离低功耗射频技术，占非授权频谱、自组网 |

| LTE | Long Term Evolution | 4G 长期演进，全球主流 4G 标准 |
| 5G | 5th Generation Mobile Communication | 第五代移动通信；三个场景见 eMBB／uRLLC／mMTC |
| eMBB | enhanced Mobile Broadband | 增强移动宽带，瓶颈在带宽的场景（高清影像、视频回传） |

| BLE | Bluetooth Low Energy | 低功耗蓝牙，短距、可组 MESH |
| ZigBee | — | 短距低功耗自组网协议，可构成 MESH |
| 6LoWPAN | IPv6 over Low-Power Wireless Personal Area Networks | 让 IPv6 跑在低功耗短距链路上的适配层 |
| ISA100.11a | — | ISA 制定的工业无线标准 |
| WirelessHART | — | 基于 HART 协议的工业无线标准 |
| WIA-PA／WIA-FA | Wireless Networks for Industrial Automation | 中国主导的工业无线标准，分过程自动化与工厂自动化两版 |
| WLAN | Wireless Local Area Network | 无线局域网 |
| PON | Passive Optical Network | 无源光网络，工业 PON 用于厂区光纤接入 |
| TSN | Time-Sensitive Networking | 时间敏感网络，IEEE 802.1 的一组以太网增强标准，用统一时钟与时间调度实现确定性传输 |
| 802.1AS | — | TSN 的时间同步标准，给全网设备同一时间基准 |
| 802.1Qbv | — | TSN 的时间感知调度标准，即“门控”：按时隙放行指定流 |
| 802.1CB | — | TSN 的帧复制与消除标准，用冗余路径降丢包 |

| VPN | Virtual Private Network | 虚拟专用网，在公共网络上构造隔离的私有通道 |
| SDN | Software-Defined Networking | 软件定义网络，控制平面与转发平面分离，由集中控制器编排 |

| CC-Link | — | 三菱体系的现场总线 |
| OPC UA | Open Platform Communications Unified Architecture | 开放平台通信统一架构（IEC 62541），工业数据的统一信息模型与访问接口 |

| NFC | Near Field Communication | 近场通信，极近距离射频识别 |

## 5 安全

| 缩写 | 全称 | 说明 |
| --- | --- | --- |
| ICS | Industrial Control Systems | 工业控制系统，含 SCADA、DCS、PLC 及其它控制系统 |
| DDoS | Distributed Denial of Service | 分布式拒绝服务，用大量受控设备发海量请求耗尽目标资源 |
| IDS | Intrusion Detection System | 入侵检测系统，只做监测告警，部署在旁路 |
| IPS | Intrusion Prevention System | 入侵防御系统，串接在链路中，识别后直接阻断（与本课 IDS 对照理解） |
| FASR | Firmware Attack Surface Reduction | 固件攻击面减少，从内核与协议栈层面削减可被利用的入口 |
| Fuzzing | Fuzz Testing | 模糊测试，向目标灌入畸形输入以触发崩溃或越界，占脆弱性测试的 80% |
| 白名单 | Whitelist | 只放行已枚举的合法指令与消息，能挡住未知攻击，代价是变更时须维护策略 |
| 可信计算 | Trusted Computing | 用硬件信任根逐级度量启动链，证明“当前运行的东西没被改” |
| 零信任 | Zero Trust | 不默认内网可信，每次访问都重新验证身份与上下文 |
| 同态加密 | Homomorphic Encryption | 密文上可直接计算、结果解密后与明文计算一致，用于“数据可用不可见” |
| 智能合约 | Smart Contract | 部署在链上、条件满足即自动执行的程序代码 |
| 联盟链 | Consortium Blockchain | 由多机构共同维护的许可链，写入权限受限、参与者可识别 |

## 6 不带缩写的关键术语

| 术语 | 解释 |
| --- | --- |
| 泛在连接 | 任何对象在任何地点都能联网并被寻址，是“物与物、物与人”连接的总称；范围比“联网”更宽，强调无处不在 |
| 全面感知 | 对物理世界的状态做多维度、连续采集，对应物联网三层中的感知层 |
| 闭环 | 把输出结果反馈回去修正输入：采样→计算→执行→再采样。工业与消费场景的分水岭就在有没有“执行”这一环 |
| 全生命周期 | 从设计、采购、生产、销售、运维到报废回收的全过程；说“数据贯穿全生命周期”，指的是每一段都可被同一标识串起来 |
| 赛博空间 | cyber space，由计算与网络构成的信息世界，与物理世界相对；CPS 就是两者之间的闭环 |
| 语义互操作 | 不仅把数据送到，还保证双方对字段、单位、量纲的理解一致；靠统一信息模型实现，与“语法互通”相对 |
| 信息模型 | 对设备、参数、单位、关系的统一描述格式；OPC UA 就是一种信息模型标准 |
| 确定性网络 | 能给出时延上界与抖动上界的网络；“平均很快”不叫确定性 |
| 时隙／门控 | 时间被切成固定片（时隙），交换机按时隙表决定此刻放行哪条流（门控），关键流因此不与背景流量争抢 |
| 断点续传 | 连接中断后从最后一个确认点继续传输；没有它，断连期间的数据就是永久空白 |
| 边缘计算 | 把计算、存储、网络能力放到靠近数据源的一侧，就近处理；解决回传时延、带宽、能耗与隐私四条约束 |
| 边云协同 | 边缘与云分工：云训练与长周期分析，边缘推理与实时控制，形成模型下发、数据上送的闭环 |
| 数字孪生 | 物理对象的数字模型，靠实时数据持续演化并与实体全生命周期保持一致，可仿真并把结果回馈实体 |
| 云制造 | 把制造资源与制造能力虚拟化、服务化，构成服务云池，用户按需获取 |
| 网络化协同 | 跨专业、跨企业、跨地域开展协同设计、仿真、生产与保障 |
| 个性化定制 | 按单生产、按需配置，要求设计、排产、供应链都能快速响应 |
| 服务化延伸 | 从卖产品延伸到卖运行保障与结果，是设备商转向服务商的路径 |
| 分散功能块 | 把控制逻辑下放到现场仪表执行，控制站变成虚拟概念；这是现场总线区别于集中式 DCS 的核心 |
| 通信线供电 | 现场仪表直接从通信线取电，危险区域不必另拉电源线；代价是仪表必须低功耗 |
| 本质安全／安全栅 | 防爆环境下的供电与限能方案：把进入危险区的能量限制在不足以点燃的水平 |
| 多源异构 | 数据来自不同系统、结构与类型各不相同 |
| 多模态 | 同一批数据以关系、图、键值、时序、非结构化等多种形态存在 |
| 时序模式 | 时序数据里的周期、趋势、相关性等结构；先挖出结构再建模，模型才不会随工况漂移 |
| 知识图谱 | 把实体与关系组织成可推理的网络；工业知识图谱沉淀的是故障、经验与因果关系 |
| 重机理 | 工业分析强调因果与物理机理，不能只靠数据拟合；异常样本稀少时，纯数据驱动无法定位根因 |
| 4–20 mA | 工业仪表的标准模拟电流信号，一对线传一个变量、单向，是现场总线要取代的对象 |
| 气隙（air gap） | 物理上不与互联网连通的内网；它只切断网络路径，不消除介质入口（U 盘、维护笔记本） |
| 横向移动 | 攻击者攻破一层后，用该层权限向相邻层渗透的手法；五类威胁因此串联成链 |
| 组织扁平化 | 压缩中间管理层级、把决策权下移到一线；在控制系统里意味着层级隔离形成的缓冲带被压缩 |
| 使能技术 | enabling technology，使平台具备工业能力的关键技术总称（感知、通信、控制、数据、孪生） |
| SLA | Service Level Agreement，服务等级协议，把可用性、响应时间写成合同条款 |
| 稼动率 | 设备在计划时间内实际运转的比例，OEE 的第一个乘数 |

| 时延 | latency，一个事件从发生到被反馈执行所经过的时间，单位 ms；必须区分平均值、上界与抖动，只看平均没有意义 |
| 抖动 | jitter，相邻数据包时延之差；闭环控制怕抖动甚于怕平均时延 |
| 串行化时延 | 数据包被逐比特推上链路的时间＝帧长 ÷ 链路速率 |
| 传播时延 | 信号在介质中行进的时间＝距离 ÷ 介质速度；光纤约 5 μs/km，空气约 3.3 μs/km |
| 带宽 | bit/s，单位时间能通过的比特数；只影响串行化时延，不决定端到端时延 |
| 连接密度 | 台/km²，单位面积可同时接入的终端数；与每台终端占用的空口资源成反比 |
| 占空比 | 发射时间占周期的比例；平均电流 ≈ 发射电流 × 占空比，直接决定电池寿命 |
| 扩频因子 | LoRa 的参数：比特展开得越宽，越能在噪声下解出，速率成比例下降——覆盖是拿速率换的 |

## 8 成对概念的判据

课件里成对出现、最容易记混的概念，判据一句话：

| 一对概念 | 判据 |
| --- | --- |
| 互联网／万维网 | 万维网是跑在互联网上的一项服务 |
| 物联网／工业物联网 | 是否用于生产、是否提升既有工业设施 |
| 工业互联网／工业物联网 | 课件口径：同义词，同时又是包含关系 |
| 工业互联网／智能制造 | 前者是依托基础、侧重工业服务；后者是最终目标、侧重工业制造 |
| 现场总线／工业以太网 | 是否沿用标准以太网的帧格式与物理层 |
| IT／OT | 服务对象是管理信息还是生产控制；OT 要求确定性与不停机 |
| 工厂内网／工厂外网 | 连接对象是否越过工厂边界 |
| 标识／标识解析 | 编号 vs 按编号查到地址与信息 |
| 被动载体／主动载体 | 有无供电与通信能力，能否主动上报 |
| 多源异构／多模态 | 来源与结构不同 vs 同一批数据的形态不同 |
| 边缘计算／边云协同 | “在何处算” vs “边与云如何分工” |
| 数字孪生／仿真 | 有无实时数据驱动与双向交互 |
| 功能架构／技术架构 | 按功能层级分层 vs 按技术属性分类 |
| 单元级／系统级／SoS 级 CPS | 互联手段是无、工业网络，还是大数据平台 |
| PLC／DCS／SCADA | 控制对象是单机、同一厂区系统，还是跨厂站分散测点 |
| 认证／授权 | 你是谁 vs 你能对哪个资源做什么 |
| 网络隔离／边界管控 | 是否保留受控通路；隔离求不可达，管控求可见可控 |
| 代码审计／脆弱性检测 | 有无源码；白盒 vs 黑盒 |
| 可信计算／零信任 | 度量平台完整性 vs 逐次验证访问请求 |
| 区块链／数据库审计 | 谁能单方面改写记录：多数节点 vs 管理员 |
