# 第零章 · 工厂速写

> 课件默认你知道工厂长什么样：“现场”“车间”“产线”“节拍”“换型”这些词从头用到尾，却一次也没解释过。没进过工厂的人读到这里只能靠猜。这一章补上底盘：空间怎么分级、人怎么排班、一天怎么运转、数据在哪产生、这些词对应课程的哪一层。

## 1 空间：厂区、车间、产线、工位、设备

工厂是一层套一层的空间，课程里的“设备层／工厂层／企业层”就架在这个结构上。

| 层级 | 规模 | 里面有什么 | 谁在这里 |
| --- | --- | --- | --- |
| 厂区（园区） | 几万到几十万平方米 | 若干栋厂房、仓库、动力站（配电、空压、制冷）、装卸区、办公楼 | 厂长、计划、采购、物流 |
| 车间（厂房） | 几千到几万平方米 | 按工艺划分的若干工段与产线 | 车间主任、工艺员、班组长 |
| 工段 | 车间内的一块区域 | 同类工序的几条产线 | 工段长 |
| 产线（生产线） | 几十米到几百米 | 按工艺顺序排列的若干工位，节拍一致 | 线长、操作工 |
| 工位 | 一到两个操作位 | 一台设备或一套工装（夹具、模具、量具的统称），完成一道工序 | 操作工 |
| 设备 | 一台机床、机器人、压机、装配台 | 主轴、刀库、伺服、液压站、电气柜 | 设备员、维修 |

**现场**指车间地面、产线旁边那块地方。说“去现场”“现场有问题”，意思是离开办公室到产线旁看实物。**一线**指直接操作设备的人。**现场级**在课程里就是这个位置：设备旁边、产线边上。

车间的划分方式是按工艺来的。汽车厂的四大工艺是冲压（把钢板压成覆盖件）→ 焊装（把覆盖件焊成白车身）→ 涂装（喷漆）→ 总装（装发动机、内饰、轮胎），四个车间依次排列，中间用立体库（自动化立体仓库：货架高十几米，由堆垛机取放）和输送线连接。机械厂则是机加车间（车、铣、磨）→ 热处理 → 装配车间。

## 2 两种车间：离散制造与流程制造

课程里 PLC、DCS、SCADA 的适用场景取决于这条区别，而课件一字未提。

| | 离散制造 | 流程制造 |
| --- | --- | --- |
| 物料 | 单件：零件、部件、整机，可数、可拆、可存 | 连续流体或粉体：化工料液、水泥、纸浆、蒸汽 |
| 组织方式 | 按工单与批次，一件一件走工序 | 按配方连续运行，调的是温度、压力、流量 |
| 停车 | 可停可启，停一台设备影响局部 | 启停成本极高，倾向 24 小时连续运行 |
| 度量 | 件数、良品率、节拍 | 产量（吨/小时）、纯度、能耗 |
| 典型控制 | PLC 做逻辑与顺序控制，MES 管工单 | DCS 做回路调节，SCADA 做广域监视 |
| 课程对应 | 机加、装配、汽车、电子 | 化工、冶金、电力、水处理 |

判据一句话：物料能不能按件数清点。能按件数的是离散，只能按流量计量的是流程。

## 3 一天怎么运转

工厂的一天由几个固定动作串起来，这些动作就是数据的产生点：

| 动作 | 谁做 | 产生什么数据 |
| --- | --- | --- |
| 交接班 | 两班或三班交接 | 设备状态、未完工单、异常记录 |
| 开班点检 | 操作工按表检查油位、气压、安全门、刀具 | 点检记录（纸质或平板） |
| 首件检验 | 换型、换刀、开机后第一件全检 | 首件报告、工艺参数确认 |
| 批量生产 | 操作工上下料（把毛坯装上、成品卸下）、监控 | 计数、报警、节拍 |
| 巡检 | 质检按小时抽检 | 尺寸、外观、抽检结果 |
| 异常呼叫（安灯） | 工位拉绳或按钮 | 呼叫时间、响应时间、停机原因 |
| 停线 | 安全、质量、缺料三类最常见 | 停机起止、责任方 |
| 班后复盘 | 班组长 | 产量、良品率、异常汇总 |

班次通常两班（8 小时 + 8 小时）或三班。**交接班是数据最容易断的地方**：上一班的异常没写清，下一班从零猜起。课程里反复讲的“数据断链”，在车间里的第一现场就是交接班记录。

## 4 生产组织：工单、排产、节拍、换型

| 词 | 含义 | 对应的数据 |
| --- | --- | --- |
| 工单 | 一张单子：做什么产品、多少件、什么交期、走哪条工艺路线 | 工单号、数量、开始与完成时间 |
| 排产 | 决定哪台设备、什么时候、做哪张工单 | 排产计划、设备占用 |
| 节拍（takt） | 客户需求决定的出件间隔 ＝ 可用生产时间 ÷ 需求数量 | 目标节拍 |
| 循环时间 | 某工位实际完成一件的耗时，超过节拍就形成瓶颈 | 实测循环时间 |
| 换型 | 从做 A 切到做 B 的准备：换模、换刀、换程序、首件确认 | 换型起止、换型耗时 |
| 在制品（WIP） | 已投产未完工的件，堆在工位之间 | 在制品数量、位置 |
| 齐套 | 装配前所需零件全部到齐 | 齐套率、缺件清单 |
| 批次／序列号 | 追溯的最小单位：同批同工艺，或单件唯一号 | 批次号、SN |

**节拍与停机的账**：OEE 里的“性能稼动率”就是拿实际循环时间与理论节拍比。一条 118 秒出一台车的总装线，若某工位实际要 130 秒，整线产能就被它卡住，这条线就是瓶颈。

**换型为什么贵**：换型期间设备不产出，还要试模、首件、调参。多品种小批量生产里，换型时间往往比故障时间更长，所以“减少换型损失”是精益生产的核心题目之一。

## 5 设备里面有什么

以一台加工中心为例，从外到里：

- **机械部分**：床身、主轴（转速与扭矩决定切削能力）、刀库与换刀机构（自动换刀，几秒一刀）、伺服电机 + 丝杠／导轨（进给）、冷却液系统、防护门与安全光栅；
- **电气柜**：PLC（控制器）、伺服驱动器、变频器、接触器与继电器、断路器、24V 电源、端子排与线槽；
- **传感与执行**：接近开关（工件到位）、光电开关（通过检测）、编码器（位置与转速）、振动与温度传感器（状态）、压力开关（气液）；执行侧是气缸、液压缸、电机；
- **人机界面**：机床面板、三色灯（绿运行／黄待机／红故障）、看板。

**数据在哪里产生**：PLC 的输入输出寄存器（I/O 点）、现场总线（Profinet、EtherCAT、Modbus）上传的变量、扫码枪读的条码、机床自带网口输出的状态（MTConnect、OPC UA）、电表与气表。课程的“采集”层，实际就是把这些口接出来。

**OT 与 IT 的物理位置**：OT 是电气柜这一侧（PLC、驱动器、总线），IT 是机房那一侧（服务器、交换机、数据库）。两者中间隔着一层网关或防火墙，这就是课程说“IT 与 OT 隔离”的实际位置。

## 6 度量：产量、良品率、OEE

| 指标 | 定义 | 说明 |
| --- | --- | --- |
| 产量 | 一段时间内的产出件数 | 分计划产量与实际产量 |
| 良品率 | 良品数 ÷ 总产出 | 与一次通过率（FPY）不同：FPY 把返修后合格的排除在外 |
| 时间稼动率 | 实际运行时间 ÷ 计划生产时间 | 扣故障、换型、待料、待检 |
| 性能稼动率 | 理论节拍 × 产量 ÷ 实际运行时间 | 扣空转、降速、小停机 |
| **OEE** | 时间稼动率 × 性能稼动率 × 良品率 | 世界级约 85%，多数工厂 40%–60% |
| MTBF | 平均无故障工作时间 | 越大越可靠 |
| MTTR | 平均修复时间 | 越小越好修 |

OEE 的三个乘数各管一件事：设备停没停（时间）、跑得够不够快（性能）、做出来的合不合格（质量）。客户要求“OEE 双方协商一致”，本质是要求这三个数的**统计口径**一致——用谁的班次划分、算不算计划检修、返修件计入哪边。

## 7 这些词对应课程的哪一层

| 课程术语 | 物理范围 | 典型系统 | 典型数据周期 |
| --- | --- | --- | --- |
| 设备层 | 单台设备、单个工位 | PLC、传感器、伺服、刀库 | 毫秒到秒 |
| 现场级 | 产线旁、设备侧 | 现场总线、I/O、边缘网关 | 毫秒到秒 |
| 车间级 | 一个车间 | SCADA／HMI、MES 执行、安灯 | 秒到分钟 |
| 工厂级 | 整个厂 | MES、WMS、能源管理 | 分钟到小时 |
| 企业级 | 多厂、集团 | ERP、PLM、SCM | 天到月 |
| 产业层 | 跨企业 | 工业互联网平台、标识解析 | 天到月 |

课件说“现场”“车间”时并不严格区分大小，读到时要按这张表对：讲实时控制指的是设备层与现场级，讲排产与追溯指的是车间级与工厂级，讲订单与协同指的是企业级与产业层。

## 8 三个常见误解

1. **“联网率 90%”数的是设备台数**，不是工位数，也不是传感器数。一台机床装十个传感器，联网率仍只算一台。
2. **“停机”包括非故障时间**。换型、待料、待检、计划检修都计入停机损失；课程里“非计划停机 4 小时到场”罚的是非计划那一部分。
3. **MES 与 ERP 的分界在工单**。ERP 管“接不接这张订单、物料够不够”，MES 管“这张订单在车间里做到哪一步、哪台设备做的、合格不合格”。工单从 ERP 下到 MES，执行结果从 MES 回到 ERP。
