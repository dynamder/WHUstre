# 第四章（下）· 标注、选择与检测

> 本页覆盖 §3 几何公差的标注、§5 几何公差的选择、§6 几何误差的检测。
> **定位格式**：`〔§3 P.N〕` = 第 4 章第 3 节 · 课件 PDF 第 N 页。
> 标注的「怎么摆、加不加 φ」是标注题/改错题的直接考点；选择与检测主要出填空选择。

## 一、几何公差的标注〔§3 P.76–99〕

### 1. 公差框格

| 格数 | 用法 | 各格内容 |
|---|---|---|
| **两格** | 形状公差（无基准） | ①项目符号 ②公差值 + 有关符号 |
| **三格** | 有单一基准 | ①项目 ②公差值 ③基准字母 |
| **五格** | 三基面体系 | ③第一基准 ④第二基准 ⑤第三基准 |

![几何公差的框格结构（项目 / 公差值 / 基准）](assets/figs/kuangge-jiegou.png)

- 第一格：**公差特征项目符号**；
- 第二格：以 **mm** 为单位的**公差值和有关符号**（φ、Sφ、Ⓜ、Ⓛ、Ⓟ、Ⓡ）；
- 第三格起：**基准字母**及其符号。**第三格永远是第一基准**，第四、五格是第二、第三基准，**与字母表顺序无关**〔§3 P.79〕。

> 例：`◎ φ0.03 Ⓜ C A B` = 同轴度、φ0.03、最大实体要求、第一基准 C、第二基准 A、第三基准 B。

### 2. 指引线〔§3 P.80〕

1. 由**箭头 + 细实线**构成；
2. 从框格的**左端或右端**引出（也允许从侧边直接引出）；
3. **可以弯折，但不得多于两次**；
4. 箭头应指向**公差带的宽度方向或直径方向**；圆形公差带时，箭头方向就是**直径方向**。

### 3. 基准符号〔§3 P.81〕

- 组成：**涂黑三角形 + 方框（或圆圈）+ 连线 + 大写字母**；
- 无论基准符号在图面上朝哪个方向，**字母一律水平书写**；
- 禁用字母：**E、I、J、M、O、P、R、F、L**（9 个）；
- 字母高度与图样字体一致。

![基准符号（涂黑三角形 + 方框 + 连线）](assets/figs/jizhun-fuhao.png)

### 4. 被测要素的标注〔§3 P.82–87〕

| 被测要素 | 箭头位置 |
|---|---|
| **轮廓要素** | 置于**轮廓线上或其延长线上**，并且**明显与尺寸线错开** |
| **中心要素**（轴线、中心直线、中心平面、球心） | 与**该要素尺寸线的延长线重合（对齐）** |

- 箭头指向**公差带宽度方向**时，公差值只写数字；
- 箭头指向**圆形公差带的直径方向**时，公差值前加 **φ**；
- 指向**球形**公差带直径方向时，加 **Sφ**。

**公共被测要素**（公共轴线、公共中心平面）：用一个框格表示，在框格上方写「共线」「共面」或同类要素的数量，用带字母的 T 形箭头分别连到各要素。

### 5. 基准要素的标注〔§3 P.88–92〕

| 基准要素 | 三角形底边 | 连线 |
|---|---|---|
| **轮廓要素** | 贴在**轮廓线或延长线**上，与尺寸线**明显错开** | 垂直轮廓线 |
| **中心要素** | 贴在**尺寸界线**上 | 与**尺寸线对齐** |

- 圆锥轴线作基准：细实线与**圆锥直径尺寸线**对齐；若圆锥用角度标注，则**正对该角度的尺寸线**；
- **公共基准**：分别标注两个不同字母（A、B），框格中写 **A-B**。

### 6. 简化标注〔§3 P.93–95〕

| 情形 | 做法 |
|---|---|
| 同一要素有几项形位公差要求 | 框格**重叠**绘出，只用**一条指引线** |
| 几个被测要素有**同一公差带**要求 | 只用一个框格，从指引线上分叉出几条带箭头的连线 |
| 几个**同型**要素有同一要求 | 只对其中一个画框格，框格上方写**数量**（如 `3×`） |

> 改错题里常出现的「叠放框格」就是第一种简化标注——合法，但**每一项必须有自己的项目符号格**。

## 二、几何公差的选择〔§5 P.158–172〕

### 1. 选择内容

选三样：**① 特征项目及基准要素；② 公差原则；③ 公差值**。

### 2. 选择公差项目要考虑〔P.159〕

1. 零件要素的**几何特征**（面 → 平面度；圆柱面 → 圆度/圆柱度；轴线 → 直线度/同轴度）；
2. **功能要求**及加工中出现误差的可能性；
3. **测量的方便性**；
4. 特征项目本身的**特点**（是否综合控制）。

> 例：平键键槽宽度方向应标**对称度**（而不是位置度）。

### 3. 选择基准要考虑〔P.160〕

1. 零件在机器上的**安装位置、作用、结构特点**；
2. 采用**单一基准、公共基准还是三基面体系**；
3. 从**设计**考虑：旋转轴件常选**与轴承配合的轴颈**或**两端中心孔**作基准；
4. 从**加工工艺**考虑：选**夹具定位**的要素；
5. 从**测量**考虑：选**计量器具定位**的要素；
6. 从**装配**考虑：选**相互配合、相互接触**的表面。

> **基准统一原则**：设计、加工、测量、装配基准最好是**同一个要素**。

### 4. 选择公差原则〔P.161〕

| 考虑因素 | 说明 |
|---|---|
| 功能要求 | 保配合 → Ⓔ；保装配 → Ⓜ；保壁厚 → Ⓛ |
| 零件尺寸大小 | 大型零件不易做边界控制 → 独立原则 |
| 检测方便性（经济性） | Ⓔ 用光滑极限量规；Ⓜ 用位置量规 |
| 公差值是否可变 | 独立原则 → **固定**；相关要求 → **可变** |

**相关要求的利与弊**：

- **利**：尺寸公差得到充分利用，经济性好；
- **弊**：形状误差的大小完全取决于实际尺寸偏离最大实体尺寸的数值，**数值过小时加工很困难**。

### 5. 选择公差值〔P.162〕

方法：**计算法**或**类比法**（标准中有表可查）。原则：

1. 满足功能要求，**取低不取高**（能用 8 级不用 7 级）；
2. 同一要素：**形状公差 < 定向公差 < 定位公差 < 尺寸公差**；
3. 与尺寸公差协调：一般几何公差精度等级**与尺寸公差同级**；要求高时可比尺寸公差高 1~2 级，要求低时低 1~2 级；
4. **孔相对于轴**的几何公差等级低 1~2 级；**细长体比粗短体**低 1~2 级；
5. 被测要素为**线**的公差值小于为**面**的公差值；
6. 单一平面的形状公差，可按**表面粗糙度 Ra ≈ 形状公差的 20%~25%** 估算。

> 类比法等级用途（了解即可）：
> - 直线度/平面度：5 级（平板、机床导轨）、6 级（普通机床导轨）、7 级（主轴箱、减速器结合面）、8~9 级（箱体、支承面）；
> - 圆度/圆柱度：5~7 级（机床主轴轴颈、与 6 级轴承配合的轴颈、与 0 级轴承配合的外壳孔）；
> - 平行度/垂直度/倾斜度：4~5 级（精密机床、量具）、6~8 级（一般机床）、9~10 级（低精度零件）；
> - 同轴度/对称度/跳动：5~7 级（IT8 及更高精度零件）、8~9 级（IT9~IT11 零件）。

## 三、几何误差的检测〔§6 P.174–191〕

### 1. 形状误差与最小条件〔P.174–176〕

- **形状误差**：实际单一要素对其**理想要素**的变动量；
- **最小条件**：被测实际要素对其理想要素的**最大变动量为最小**；
- **最小区域**：包容实际要素、具有**最小宽度或直径**的包容区域；
- 评定形状误差时，用**最小区域的宽度或直径**表示误差值。

> 一句话：形状误差的「理想要素位置」不是随便摆的，要摆到**让误差最小**——这就是最小条件。

### 2. 三个评定准则〔P.177–184〕

| 项目 | 最小区域判别准则 |
|---|---|
| **直线度**（给定平面） | 两平行直线包容实际直线时，实际直线与两包容直线至少**高、低、高**（或低、高、低）**三点接触** |
| **平面度** | 两平行平面包容实际平面时，至少有**四个极点**分别与两平面接触，且满足**三角形准则**或**交叉准则** |
| **圆度** | 两同心圆包容实际圆时，实际圆至少有**内、外交替的四点**与两圆接触 |

补充：直线度也可用**两端点连线法**评定，$f_{BE}=h_{max}-h_{min}$（近似方法，最小条件法才是仲裁方法）。

### 3. 五大检测原则〔P.185–190〕

| 原则 | 做什么 | 典型器具 |
|---|---|---|
| **与理想要素比较** | 把被测要素与理想要素直接比较 | 刀口尺、平尺、平台、样板（光隙法/厚薄规） |
| **测量坐标值** | 测各测点坐标，再数据处理 | 三坐标测量机、工具显微镜（位置度、轮廓度最常用） |
| **测量特征参数** | 测有代表性的参数近似表示误差 | 两点法测圆度；几个方向测直径差之半当圆柱度 |
| **测量跳动** | 绕基准轴线回转，读指示表最大变动量 | 顶尖+心轴（圆跳动）、V 形块（圆跳动/全跳动） |
| **控制实效边界** | 检验是否超出实效边界 | **位置量规**（按 MMVB 尺寸做量规） |

> **位置量规**（P.190 例）：工件被测要素的 MMVB 为 φ12.04，则量规测量部分的基本尺寸取 φ12.04；基准遵守包容要求 → 量规定位部分按 MMB（φ25）做。

### 4. 未注形位公差〔P.191〕

为简化制图，一般机床加工就能保证的形位精度**不必标注**，按 GB/T 1184 执行：

- 未注**直线度、垂直度、对称度、圆跳动**各分 **H、K、L** 三级，在标题栏或技术要求中注出，如 `GB/T 1184—K`；
- 未注**圆度**公差值 = 直径公差值，但不得大于径向跳动的未注公差；
- 未注**圆柱度**不作规定，由圆度、直线度和相应素线平行度的公差控制；
- 未注**平行度** = 尺寸公差值 或 直线度/平面度公差值中**较大者**；
- 未注**同轴度**未作规定，可与径向圆跳动公差相等；
- 未注**线/面轮廓度、倾斜度、位置度、全跳动**由各要素的注出或未注尺寸/角度公差控制。

## 四、本章在考试中的落点

| 题型 | 分值 | 从本章出什么 |
|---|---|---|
| 填空 / 选择 | ~30 分中的一部分 | 14 项分类与符号、公差带形状、φ 的用法、公差原则的定义与符号 |
| 标注题（陈述式） | 10 分 | 把技术要求标到图上（框格、基准、Ⓔ/Ⓜ、方框尺寸） |
| 标注题（应用） | 15 分 | 轴承/键/花键/螺纹的装配图标注 |
| 改错题 | 15 分 | 找 φ、基准、箭头摆放、指引线、公差值次序的错误 |

> **一句话总结第四章**：**要素分类**决定「标谁」，**公差带形状**决定「加不加 φ」，**公差原则**决定「尺寸公差和形位公差怎么互相让」，**标注规则**决定「怎么画」。

## 五、第 4 章速查卡

- 14 项：形状 6（直线、平面、圆、圆柱、线轮廓、面轮廓）+ 定向 3（平行、垂直、倾斜）+ 定位 3（同轴、对称、位置）+ 跳动 4（径向圆/端面圆/斜向圆/径向全/端面全）。
- 公差带 11 种形状；同轴度、位置度恒加 φ；直线度/平行度/垂直度**任意方向**才加 φ。
- 框格：2 格 = 无基准；3 格 = 单基准；5 格 = 三基面。第三格 = 第一基准。
- 指引线弯折 ≤ 2 次；基准字母禁 E/I/J/M/O/P/R/F/L。
- 公差值次序：形状 < 定向 < 定位 < 尺寸。
- 公差原则：独立（无符号）| Ⓔ 保配合 | Ⓜ 保装配 | Ⓛ 保壁厚 | Ⓡ 可逆。
- 边界：MMB = $d_{max}$ / LMB = $d_{min}$ / MMVB = $d_{max}+t$ / LMVB = $d_{min}-t$（轴）。
- 作用尺寸：$d_{fe}=d_a+f$、$D_{fe}=D_a-f$（对配合）；$d_{fi}=d_a-f$、$D_{fi}=D_a+f$（对强度）。
- 检测原则：理想要素比较、坐标值、特征参数、跳动、实效边界。
